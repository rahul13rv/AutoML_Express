# 🤖 AutoML Platform

An end-to-end Automated Machine Learning (AutoML) web application built using Python and Streamlit.

## 🚀 Features

- Upload CSV and Excel datasets
- Exploratory Data Analysis (EDA)
- Missing values and duplicate detection
- Data visualization and correlation heatmaps
- Target column selection
- Regression and Classification
- Automated data preprocessing
- Multiple Machine Learning algorithms
- Model evaluation and comparison
- Cross-validation and hyperparameter tuning
- Download trained models
- Generate PDF analysis reports

## 🛠️ Technologies Used

- Python
- Streamlit
- Pandas and NumPy
- Scikit-learn
- Matplotlib and Seaborn
- Joblib
- ReportLab

## ⚙️ Installation

Clone the repository:

```bash
git clone YOUR_GITHUB_REPOSITORY_URL
cd AutoML-Platform
```

Install dependencies:

```bash
pip install -r requirements.txt
```

Run the application:

```bash
streamlit run app.py
```
